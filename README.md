# 🚀 AI Resume Analyzer  

An AI-powered Resume Analyzer built using **Python, Streamlit, Tesseract OCR & GPT-Vision**.  
It extracts text from resumes, identifies missing skills, provides job-role scores, and generates a clean professional PDF report.

---

## 🔗 Live Demo  
👉 **https://ai-resume-analyzer-khrajj29es5wsgaekz8hxt.streamlit.app/**

---

## ⭐ Features

- 📄 **Resume Text Extraction** (OCR + PDF Reader)
- 🤖 **AI-Powered Analysis** (GPT Vision)
- 📊 **Skill Matching Score**
- 🧩 **Missing & Found Skills List**
- 📝 **Auto-Generated Professional Report (PDF)**
- ⚡ Clean & Fast UI (Streamlit)
- 🖼️ Image & PDF both supported
- 🌐 Fully deployed — shareable link

---

## 🛠️ Tech Stack

- **Python 3.11**
- **Streamlit**
- **OpenAI GPT-Vision**
- **Pytesseract / PDFPlumber**
- **FPDF**
- **GitHub + Streamlit Cloud**
